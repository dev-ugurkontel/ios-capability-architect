# Policy attestation evidence

These notes support, but do not replace, the submitter's human review of the exact portal statements.

## Data and authentication

- The skills-only package has no hosted service, account, login, OAuth flow, API key, payment, analytics, telemetry, advertising, or remote database.
- The packaged CLI makes no network requests and reads only the local inputs explicitly placed in scope by the user and host.
- Project-audit output excludes source contents, credentials, and signing material by contract.
- The repository privacy notice distinguishes plugin behavior from host-model and optional browsing behavior.

## Safety and platform integrity

- Instructions prohibit private APIs, hidden entitlement acquisition, App Review bypasses, permission dark patterns, and unsupported background guarantees.
- Managed entitlements remain explicit manual-review items.
- Catalog-only technologies are never promoted to verified recommendations without reviewed official evidence.
- Unknown, beta, deprecated, device-, hardware-, region-, and language-constrained states remain visible.

## Intellectual property

- Source and submission package are MIT licensed.
- Bundled runtime dependency notices are generated from the locked dependency graph.
- Apple names are used descriptively; the project does not include Apple logos or claim Apple endorsement.
- The listing icon is the Fillbyte mark and follows the public Fillbyte brand guide.

## User control

- The plugin does not make external changes, send messages, purchase products, deploy code, or modify Apple Developer resources.
- The audit CLI is read-only. Any later remediation change requires a separate, explicit user request and the host's normal review controls.
- Users can inspect the full source, release checksum, SBOM, registry evidence, and known limitations.

## Submission-day confirmation

Before attesting, compare the uploaded archive checksum with the GitHub release, scan the complete portal preview, run all eight reviewer cases, and verify that no portal wording broadens the product beyond these boundaries.
