# Support

## Where to ask

- Use GitHub Discussions, when enabled, for setup questions, architecture discussions, and usage help.
- Use the bug report template for reproducible defects in a skill, plugin, MCP tool, validation script, or bundled runtime.
- Use the capability correction template for missing or inaccurate Apple-platform records.
- Use the feature proposal template for new tools, workflows, or supported use cases.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for private conduct reports.

Before opening a request, search existing issues and confirm that you are using Node.js 24.x, a clean `npm ci` installation, and the latest released plugin version.

## What to include

Provide the affected skill or plugin, its version or commit, operating system, Node.js and npm versions, Codex host version where relevant, exact command or tool name, expected behavior, actual behavior, minimal reproduction, and sanitized logs. Never post credentials, signing material, Apple account identifiers, private application content, or personal health/location data.

## Support boundaries

Maintainers can help with this repository's documented behavior. They cannot provide Apple Developer Program access, managed entitlements, App Review approval, legal advice, privacy compliance certification, or support for private Apple APIs. Recommendations are architecture guidance and must be validated against the target app's actual account, provisioning, hardware, region, OS, and review context.

This is a community-maintained open-source project. Response times are best effort and no service-level agreement is provided.
